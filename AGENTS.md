# Призначення проєкту

Це компонентна HTML/JavaScript/SCSS-верстка на Vite. Користувач збирає проєкт і передає готову збірку WordPress-розробнику для подальшої інтеграції.

- Зберігай поточну структуру компонентів і спосіб підключення HTML, JS та SCSS.
- Не мігруй проєкт на React, TypeScript або інший стек без прямого запиту.
- Реалізовуй верстку, адаптивність та потрібні інтерфейсні взаємодії.
- Backend, авторизацію, збереження даних і WordPress-інтеграцію виконує WP-розробник. Не додавай API-запити, вигадані endpoints або backend-контракти без прямого запиту.
- Перевіряй роботу в dev-режимі та коректність production-збірки. Результат має бути придатним для передачі WP-розробнику.

# Візуальні стани елементів

Не додавай outline або окремі візуальні стилі для `:focus` та `:focus-visible`, якщо користувач прямо цього не попросив.

Зберігай роботу клавіатурної навігації та функціональне керування фокусом.

# Повідомлення валідації форм

Повідомлення `[data-fls-form-error]` мають бути абсолютно позиціонованими відносно обгортки поля з `position: relative`. Вони не повинні змінювати висоту форми або зсувати сусідні поля. Дотримуйся наявного підходу в інших формах проєкту.
